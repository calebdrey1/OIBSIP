## About the Project

A responsive temperature conversion web application that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Features

- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Validate user input.
- Prevent temperatures below absolute zero.
- Responsive design for mobile and desktop.
- Reset conversion results.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.
4. Enter a temperature, select the units, and click Convert.

## Conversion Formulas

- Fahrenheit = (Celsius × 9/5) + 32
- Celsius = (Fahrenheit − 32) × 5/9
- Kelvin = Celsius + 273.15
